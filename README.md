# React HTML V 1.0

Halaman sederhana dengan empat tombol: Info, Success, Warning, dan Error. Setiap tombol menampilkan notifikasi React Toastify.

## Menjalankan

1. jalankan `npm.cmd install` di Powershell lalu `npm.cmd run dev`.
2. jalankan `npm.cmd install`di powershell  lalu `npm.cmd run build`
3. Buka alamat yang ditampilkan, biasanya `http://localhost:5173`.

Halaman demo tersimpan di `public/legacy/index.html` dan ditampilkan lewat aplikasi React.
